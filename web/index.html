Is the Label Telling the Truth?

Seafood is hard to recognise once it is filleted, breaded or turned into surimi. This project reads the DNA of 20 processed seafood products and compares it with the species on the label, using DNA barcoding against a reference built from BOLD and NCBI RefSeq.
